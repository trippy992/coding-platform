# Coding Platform

A LeetCode-style coding platform. This repository contains both the frontend and the backend as separate folders (monorepo).

## Structure

```
coding-platform/
├── frontend/   # React + Vite + Redux Toolkit + Tailwind CSS + DaisyUI
├── backend/    # Backend API (coming soon)
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Tooling

- **Build:** `npm run build` (inside `frontend/`)
- **Lint:** `npm run lint` (inside `frontend/`)
